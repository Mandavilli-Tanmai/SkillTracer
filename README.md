# SkillTracker – Personal Skill Progress

SkillTracker is a web application designed to help users organize their learning journey and track personal skill development.

### Features
- **Skill Management:** Add and manage skills you want to develop.
- **Goal Setting:** Set learning goals and track your progress.
- **Course Management:** Organize courses and learning resources.
- **Progress Tracking:** Monitor your development over time.
- **Interactive Dashboard:** View your skills, goals, courses, and progress in one place.

### Technologies Used
- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite (default Django database, if configured)

### Objective
To provide a simple and organized platform that encourages continuous learning, goal setting, and personal development.
